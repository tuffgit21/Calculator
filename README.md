Free to use lightweight Calculator for everyone!
to Rebuild the calculator:
    1. On Windows:
        Use PyInstaller (pip install PyInstaller) or auto-py-to-exe (pip auto-py-to-exe)
    2. On Debian-based distro (example: Ubuntu, Zorin OS, Linux Mint, etc...)
        a. Use the same structure as the Calculator-source-deb folder
            I. run dpkg-deb --build (FILE_NAME) expected file: FILE_NAME.deb
